# Gexp Leaderboard

Dynamic GEXP Leaderboard that auto resets

Supports monthly and yearly leaderboards. Configure either board with `/setup-gexp-leaderboard`; both are refreshed hourly and automatically use the current UTC month or
year.

- `/gexp-month` displays the selected month in the current year.
- `/gexp-year` displays a year (defaults to the current year).
